1. Install Android Studio (Koala or newer), File > Open > this folder, let Gradle sync.
2. Plug in your phone (USB debugging on) and press Run.
3. Press Home and choose "Liquid Launcher" > Always.
Default passcode 1234. Change it in Settings.
If SMS or phone permissions are greyed out on Android 13+: App info > three dots > "Allow restricted settings".

No Android Studio? Build the APK online:
1. Create a free GitHub account and a new repository.
2. Upload every file from this folder (keep the .github folder).
3. Open the Actions tab > "Build APK" > wait for the green check.
4. Open that run, download "LiquidLauncher-apk", unzip it, and install app-debug.apk on your phone (allow "install unknown apps").
